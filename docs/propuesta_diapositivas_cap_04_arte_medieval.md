## 7. Formato de datos propuesto (por diapositiva)

Se reutiliza el esquema actual de `fichas → tarjetas` y se añaden dos campos:
`imagen` (fotografía local de la diapositiva) y `texto` (el rótulo corto que se ve en pantalla).

```json
{
  "id": 2,
  "tipo": "teoria",
  "titulo": "2. Presentación: El Arte Andalusí",
  "descripcion": "Diapositivas narradas para descubrir el arte islámico.",
  "icono": "🕌",
  "fichas": [
    {
      "titulo": "El arte andalusí",
      "subtitulo": "El arte islámico de la Península",
      "icono": "🕌",
      "tarjetas": [
        {
          "nombre": "Su arco característico",
          "fecha": "Arte islámico",
          "icono": "🐴",
          "color": "#10b981",
          "imagen": "data/cursos/5_primaria/ciencias_sociales/tema_06_castillos/cap_04_arte_medieval/assets/a04_arcos_herradura.jpg",
          "texto": "Arco de herradura",
          "locucion": "Su arco más característico es el arco de herradura...",
          "puntos": ["El **arco de herradura** se parece a una herradura de caballo."]
        }
      ]
    }
  ]
}
```

- `locucion` → lo que dice la voz.
- `texto` → rótulo corto visible (poco texto, como pediste).
- `imagen` → ruta local obligatoria; cada diapositiva necesita su imagen dentro de `assets/`.
- `puntos` → **texto de apoyo/accesibilidad** opcional; nunca sustituye a la imagen ni a la locución.
- Para narraciones dirigidas a niños de 10 años, preferir frases cortas y palabras comunes; explicar los términos históricos necesarios con una definición sencilla.
- Comprobar que cada detalle visual nombrado por la voz (por ejemplo, el rosetón) aparezca de forma clara en la imagen de esa diapositiva. Si se mencionan varios detalles, usar una composición de imágenes o ajustar la narración.
